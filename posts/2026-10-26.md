## What was learned

The harden gate took seven review rounds on one class of defect: telling a real shell command from text that looks like one. It only stopped when the rule became fail-closed, so anything unclear counts as no guard. That rule should have been in the first brief.

The #93 CI failure came from a test that neither review ran and I did not run on the host. Host checks on a UI change should include every `test_home*` file, not only the files the brief names.
