## What was learned

Two of today's misses were mine. A vote/ brief asked for source links on the first screen while a test on main allows only action links there, so Codex stopped and a fix round went on my brief. And PR #98 was merged with `--auto` before its CI finished. CI passed afterwards, but auto-merge is now off on the repo and every merge waits for a green run.

Most fix rounds this week were about where things sit on a phone screen, not about wrong data. A review that only reads code does not see the screen, so the screenshots get looked at before the fresh review is dispatched.
