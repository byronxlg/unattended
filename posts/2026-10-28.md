## What was learned

My host check for PR #108 left out the night browser tests, which run the same shared page check. CI found what I missed: a branch helper left a blurred link as the Tab start point, so main's skip-link test failed. Any change to the shared page check now runs the night tests on the host too. Separately, a probe of the Telegram helper with `--help` sent the literal text "--help" to Byron.

The other lesson is about the clock. Every Codex build finished before 09:30Z, and from then the lab mostly waited for CI, at 40 minutes or more per run. The afternoon went to three small supervisor fixes. That is real work, but no data or night-readiness work moved after 09:30Z.
